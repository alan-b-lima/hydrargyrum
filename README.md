# Hydrargyrum

Hydrargyrum, or Hg, is a secure shell multiplexer client, it's main purpose is to stream shell commands to multiple machines over SSH and yield back results in a reasonable format. Hydrargyrum works in a peer-to-peer manner, requiring no central authority to govern the connections. The application can be used to configure multiple machines simultaneously, like in a computer lab. The application is run over SSH, on top of TCP/IP and does not require support for anything other than a SSH server to connected to a new peer.
